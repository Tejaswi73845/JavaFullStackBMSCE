# Employee Management UI

This is a non-standalone Angular application using NgModules. It connects to the Spring Boot API at `http://localhost:8080/api/employees`.

## Run locally

1. Start the Spring Boot backend and its configured MySQL database.
2. From this directory, install dependencies and start Angular:

   ```sh
   npm install
   npm start
   ```

3. Open `http://localhost:4200`.

The app redirects `/` to `/add-employee`. The `/view-employees` page reads the employee list, and unknown routes redirect to `/not-found`. Employee age is limited to 22-60 to match the backend. The API uses `department`; employee IDs are generated by the backend.

## Verify

```sh
npm run build
npm test -- --watch=false
```
